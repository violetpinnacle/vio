# Violet Pinnacle — Premium Website (v2)

A static, multi-page website project for Violet Pinnacle.

## Included
- `index.html` — homepage with eight main service categories
- `gst.html`, `audit.html`, `tds.html`, `accounting.html`, `pan.html`, `dsc.html`, `msme.html`, `training.html` — service detail pages
- `about.html`, `contact.html`
- `style.css`, `script.js`
- `assets/` — original Violet Pinnacle logo, existing relevant assets, and custom hero visual

## Preview
Extract the ZIP, then open `index.html` in a browser. For best local testing, use a local static server (optional). No build step is required.

## Publish to Netlify
Create a new GitHub repository for this folder, upload all files and folders to the repository root, then create a separate Netlify site connected to that repository. This keeps the existing live website unchanged.

## No paid features
This is a static informational website. It has no paid APIs, subscriptions, checkout, or server-side form. The contact enquiry helper opens WhatsApp with a draft message for the visitor to review. Google Fonts are an optional external resource; system fallback fonts are included.

## Important notes
- The site uses the original supplied logo. Other graphics are refreshed or repurposed from the supplied project, with a generated hero visual.
- Service wording is informational. Statutory certification, regulated professional opinions and UDIN generation must be performed by an appropriately qualified and authorised professional where required.
- Check all service descriptions, phone number, address and business details before publishing.
